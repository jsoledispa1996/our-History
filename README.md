# 💕 Nuestra Historia de Amor

Una página web hermosa y profesional que celebra tu relación con tu novia. Una línea de tiempo interactiva que cuenta la historia de los momentos compartidos desde el **8 de Mayo** hasta **Octubre 8** (5 meses de amor).

## 🎯 Características

✨ **Diseño Premium**
- Gradientes modernos y animaciones suaves
- Interfaz profesional y elegante
- Efectos visuales hermosos

📸 **Galerías Organizadas por Mes**
- Fotos de cada momento especial
- Lightbox interactivo para ver en grande
- Transiciones suaves y hover effects

🎬 **Videos Integrados**
- Videos por mes en modal player
- Reproducción directa en la página
- Fácil de visualizar

⏱️ **Contador de Días**
- Calcula automáticamente los días juntos
- Actualiza cada hora
- Muestra el progreso del amor

📅 **Timeline Interactivo**
- Visualización mes a mes
- Animaciones al desplazarse
- Sección de futuro (misterio)

📱 **Responsivo**
- Funciona perfecto en móvil, tablet y desktop
- Diseño adaptable a cualquier pantalla

## 🚀 Cómo Usar

1. **Abrir la página**: Simplemente abre el archivo `index.html` en tu navegador
2. **Explorar**: Desplázate por la página para ver todos los momentos
3. **Ver Fotos**: Haz clic en cualquier foto para verla en grande
4. **Ver Videos**: Haz clic en los videos para reproducirlos
5. **Cerrar**: Presiona ESC o haz clic fuera para cerrar lightbox/modal

## 💡 Personalizaciones Posibles

- Agregar más fotos: Simplemente copia nuevas fotos a la carpeta `images/` con el nombre `mes_numero.jpg`
- Agregar más videos: Copia videos a las carpetas de meses en `videos/`
- Cambiar colores: Edita las variables CSS en `styles.css` (línea 12-19)
- Cambiar textos: Edita los textos en `index.html`
